# First prospective model-comparison batch — v1.14.0

Empty fixture only. Connect, allow automatic zero verification, and capture unloaded tare before loading the preset. Select **Model Comparison — Current vs Wider Cubic (Empty)**, Load Preset, Start, then **Run Model Comparison**. Review the full plan and confirm fixture clearance. One setup is used throughout. Start at run defaults to 1; a later starting run creates a new batch with earlier stages explicitly skipped. Do not skip the two commissioning runs on the first use of this candidate.

Runs 1–2: frozen wider cubic at +/-5 and +/-10 degrees, 5 degrees/s, one cycle each. Runs 3–8: speeds 0.5, 5, 20, Current then Candidate at each speed. Runs 9–14: speeds 20, 5, 0.5, Candidate then Current. Main runs use +/-15 degrees, acceleration 100 degrees/s², three cycles each. Total: 38 numbered cycles. Allow 45–60 minutes including preparation/settling; duration is an estimate.

The candidate is the wider direction cubic fitted from batch 408453cc, not the fifth-order candidate. Coefficients are frozen in east_wide_candidate.py and logged with its distinct model ID. Both models use the same per-run initial increasing-branch origin alignment; numbered-cycle origins remain fixed. This tests that operational alignment procedure, not a model with no alignment. The candidate is selected only for its labelled runs; the normal GUI model choice is unchanged.

There are no rotary endpoint corrections in this batch. Rotary feedback measures the uncorrected result and supervises health/zero. Slow legs longer than 30 seconds are divided into bounded motor submoves; intermediate stops are expected and recorded in each segment's submoves count. Exclude stops/acceleration from constant-speed analysis. Global move timeout, recording, ownership and Stop checks remain active. The commissioning stages prove only that the operation completed with the existing checks; they do not impose a new accuracy acceptance requirement.

Any fault or zero-return miss halts the batch. Original recordings remain unchanged. Reconnect/check zero as required, then select the appropriate starting run in a new batch. No experiment silently retries, no automatic coefficient refitting occurs, and no loaded-AFO reliability claim is supported. A separate feedback-control comparison is not part of this first batch.

Analyse unnumbered positioning separately, then endpoint/trajectory errors, speed, direction, run/cycle repeatability and post-idle zero.
